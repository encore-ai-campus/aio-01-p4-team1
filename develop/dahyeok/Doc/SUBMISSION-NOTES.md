# 워크플로우 설계서 취합 메모 · 다혁

공통 `docs/WORKFLOW-DESIGN.md`의 작성 책임은 다혁이며 파일 편집·제출 취합은 오현님이 맡는다. 다혁 담당 원고는 [WORKFLOW-DESIGN-DRAFT.md](WORKFLOW-DESIGN-DRAFT.md)에 작성했다. 공통 문서에 반영할 때 다음 상태를 유지한다.

- 구현 기준: Git 반영본 `workflows/oke-support-12.json`(`05f7724`), 로컬 수정 중인 `workflows/oke-support-13.json`은 미커밋. 실제 게시 대상·최종 파일명은 팀 확인 후 결정한다.
- 12의 합성 HTTP 응답 검사 12/12와 Mock 회귀 56/56은 실제 서비스 실행 결과가 아니다.
- 13의 로컬 n8n 실행 25건은 `HANDOFF.md`에 기록됐지만 C03·C04가 404였고 정식 runs 보고서는 아직 없다. 실행 성공을 WF 기능 통과로 합산하지 않는다.
- 자동 답변 품질 임계값, C03 실제 근거·권한, C04 실제 티켓·알림·DLQ, FastAPI 문의 저장·재시도, 프로젝트 n8n·공식 `flow.py`·팀 VM 결과는 미확인이다.
- 오현님은 유빈님 검색/색인, 원민님 이관/오류/시험, 지혜님 인증/저장 자료를 각 담당자의 실행 근거로 받은 뒤 공통 설계서의 해당 절을 갱신한다. 기존 공통 초안의 “구현 예정” 표시는 실제 상태와 대조해 수정한다.

설계 원고의 시험 결과와 버전 상태는 취합 직전에 다시 대조한다. 비밀값·실제 연락처·실행 화면 원문을 공통 설계서에 옮기지 않는다.
