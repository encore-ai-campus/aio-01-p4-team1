# 오현님 · 팀장 작업 범위

루트 AGENTS.md를 함께 따른다.

- 허용 범위: develop/ohyun 및 사용자가 지정한 루트 공통 문서·계약·설정·최종 제출 취합.
- 공통 문서는 오현님이 편집한다. 일반 담당자의 공통 파일 읽기 전용 규칙과 구분한다.
- 다른 사람 기능 코드는 소유자에게 재현 자료와 함께 수정 요청한다.
- 개인 결과물은 문서·계약·실제 실행 근거를 검토해 취합한다. 서로 다른 기술 선택을 문서마다 독립 확정하지 않는다.
- 현재 같은 저장소에서 병렬 작업하는 경우 다른 담당자 변경을 되돌리거나 일괄 포맷하지 않는다. 작업 종료와 범위를 확인한 뒤 팀장이 Git 반영한다.
- 팀 VM 환경값·키·비밀번호를 문서·로그·커밋에 남기지 않는다.
- GitHub 마일스톤/보호 규칙·VM 배포·공통 시험은 실제 수행한 경우에만 완료로 기록한다.
