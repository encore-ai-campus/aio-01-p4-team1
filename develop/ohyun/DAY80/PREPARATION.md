**오늘 목표:** 우리 팀의 주제·역할·설계 초안을 GitHub에서 설명하고, 팀 VM의 실제 동작과 남은 일을 보여 준다. 오현님은 자료 취합·기준 확인·병합·VM 배포·발표를 맡는다.

1. 이 문서로 지금 준비할 일을 고른다.
2. [TEAM-INPUTS](TEAM-INPUTS.md)에서 이미 올라온 자료와 추가로 받을 결과를 확인한다.
3. [PRESENTATION](PRESENTATION.md) 순서로 5교시 점검·8교시 발표를 준비한다.

## 브랜치와 결과 기록

- 이 준비판과 공통 문서는 main에서 관리한다. submission에서 docs/를 직접 수정하지 않고 main → submission merge로만 가져온다.
- 수업 중 VM 배포는 검토·병합한 기본 브랜치 커밋을 기준으로 한다. 팀원 작업 브랜치를 바로 VM 기준으로 쓰지 않는다.
- 최종 제출은 제출 저장소의 Default branch 기준이다. submission 푸시만으로 제출 완료가 되지 않는다.
- 실제 통과 수·색인 수·배포 커밋·피드백은 공통 DAY80/설계서/결과서에 기록하고 이곳에는 해당 근거 링크만 연결한다.

팀장 전체 작업 기준은 [기존 TODO](../Doc/TODO.md)·[SPEC](../Doc/SPEC.md)·[IMP-PLAN](../Doc/IMP-PLAN.md)을 따른다.
