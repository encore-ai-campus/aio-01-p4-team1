# 81일차 · 팀원에게 받을 자료

오늘 받을 결과의 요청안이다. 현재 완료 상태나 상대 확인을 의미하지 않는다. 담당자는 자기 폴더에서 기능·자료를 관리하고, 오현님은 받은 근거로 main의 공통 문서를 완성한다.

## 요청하는 보고 형식

```text
담당 / 단계 / 소스 커밋 / 실제 제공 파일:
정상 입력·출력 / 오류·권한 경계:
실행 환경·명령 / practice 또는 app / Mock 또는 실제:
기대 / 실제 / 보고서·가린 캡처:
공통 문서에 반영할 절과 내용:
미완료·실패 / 수정 소유자 / 필요한 상대 / 다음 확인:
```

각자 Doc/SUBMISSION-NOTES.md 또는 기존 HANDOFF의 경로·커밋을 공유하도록 한다. 다른 담당자의 파일을 대신 수정하지 않는다. 실측값·원 보고서·최초 실패는 보존한다.

## 연결 확인 책임

- 수언님 ↔ 지혜님: 로그인 쿠키·첫 변경·역할·목록/오류와 실제 화면 연결.
- 지혜님 ↔ 다혁님: 세션 직원→공통 user·입출력·시간 제한·실제 support 호출.
- 다혁님 ↔ 유빈님: query/access_levels→근거·빈 검색·503와 실제 답변 판단.
- 다혁님 ↔ 원민님: 이관 요청·실제 ticket/사유/ACK·부분 실패 매핑.
- 원민님 ↔ 지혜님: app 저장·동시/반복 요청 티켓1건·알림/DLQ 관측.
- 유빈님 ↔ 지혜님: pgvector·문서/청크 테이블·권한·거래·실제 색인/검색/복구.
- 오현님: 계약 변경이 필요할 때 공통 반영, 검토·병합·VM 기준 커밋 관리.

기존 계약대로 진행할 때 추가 사전 승인을 기다리지 않는다. 실제 연결 불일치와 정책 변경만 담당 상대와 검토하고 오현님이 공통 문서에 반영한다.
