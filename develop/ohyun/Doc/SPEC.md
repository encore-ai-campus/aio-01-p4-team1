## PR 한 건에서 받을 내용

- 담당자·요구 ID·수정 경로·계약 ID와 기준 커밋
- 변경 동작·예상 입력/출력·권한/오류 경계
- 실제 확인 명령·결과·보고서/가린 캡처 경로
- Mock 사용 여부·미실행·남은 문제·다음 연결 담당
- 공통 계약 변경이 있으면 자기 HANDOFF 제안과 상대 검토 근거

## 반려·보류 기준

다른 담당자 파일 수정, 무단 계약 변경, 비밀값 노출, 실행하지 않은 PASS, 근거 없는 성공 수치, 실패 은폐는 수정 요청한다.
상대 서비스가 아직 없어 Mock만 확인한 PR은 Mock 단계임을 명시해 제한된 범위로 검토한다.
실제 통합 완료 판정은 실제 요청·저장·권한·회귀 확인 뒤에만 한다.

공통 계약·DB 변경은 이 문서가 아니라 루트 기준 문서에 한 번만 반영한다.
