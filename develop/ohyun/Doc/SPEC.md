# 오현님 · SPEC

작업 기준: [내 작업·협의 안내](WORK-GUIDE.md) · [내 협의 기록](HANDOFF.md). 공통 파일과 상대 폴더는 직접 고치지 않고 소유자에게 요청한다.

주 담당: 오현님. 상태: 운영 기준 초안, 배포·시험 미실행.

| 항목 | 확인 기준 |
| --- | --- |
| 파일 경계 | 6명 모두 자기 이름 폴더와 연결 상대·소유 파일을 설명 가능 |
| API | 웹·search·handoff의 정상·오류 예시를 담당자끼리 합의하고 공통 계약에 반영 |
| P0 | 실행 뼈대·DB 초기화·환경변수 이름·공통 웹훅 골격의 실제 확인 기록 |
| P1 | 로그인·문의·근거·이관·관리자 처리와 필수 권한·중복·장애 시험의 실제 결과 |
| P2 | 필수 완료 뒤 범위·일정에 맞는 가점 후보만 선택, 81일차 동결 준수 |
| 배포 | 승인한 기본 브랜치 커밋과 VM 버전 일치, 배포 뒤 회귀 결과 기록 |
| 제출 | [취합 안내](../SUBMISSION.md)의 루트 경로·필수 문서·실제 보고서 완비 |

마일스톤 날짜·첫 통합 시각·지원 역할은 추가 합의한다. 운영 문서만 준비한 상태를 기능 완료로 표시하지 않는다.
