80일차 발표는 주제/역할 2분, 본체 흐름 3분, RAG 2분, VM 확인·남은 문제 3분을 준비한다. 구현되지 않은 웹·검색·티켓 기능은 계획으로 구별한다. 당일 모든 웹 기능 완성을 전제로 잡지 않는다.
실제 승인·키트 실행·VM 배포·시험·팀원 확인은 아직 미완료이며 위 항목은 수행 뒤 체크한다.
