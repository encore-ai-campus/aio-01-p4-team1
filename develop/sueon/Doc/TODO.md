## 목적과 사용자

제공된 가상 직원 6명이 계정을 받아 로그인하고, IT 질문의 규정 근거·보완할 정보·이관 결과를 구별하게 한다. 직원은 자기 문의만 조회한다. IT팀 김민지·정우성의 관리자 계정은 티켓·알림·계정을 관리한다. 신원·부서·역할·권한은 서버 세션 기준이며 화면 입력으로 정하지 않는다.

체크는 실제 구현과 확인을 끝낸 뒤 표시한다. 현재 전 항목 미구현·미실행이며 상위 담당자 검토 전이다. 문서 작성이 협의·시험 완료를 뜻하지 않는다.
