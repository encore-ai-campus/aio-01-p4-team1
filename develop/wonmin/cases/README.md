# 시험 시나리오

- **작성:** `team.json`에 우리 팀 질문 5개 이상. 각 케이스의 입력·조건·기대 `route`와 근거·티켓을 구현 전 적는다.
- **규칙:** 정상, 애매한 문의, 권한, 이관, 장애를 포함한다. 실행 결과에 맞춰 기대값을 바꾸지 않는다. 기본 주제의 공통 14개는 80일차 키트 원본을 그대로 사용한다.
- **결과:** 공통 14유형과 팀 시나리오의 통과 수를 `develop/wonmin/runs/` 보고서에서 확인할 수 있어야 한다.
