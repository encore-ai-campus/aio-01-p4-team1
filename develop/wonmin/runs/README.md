# 실행 증거

- **작성:** `flow.py test`·반복 시험·장애 시험·`bench`로 실제 생성된 JSON 보고서를 보관한다.
- **규칙:** 실패와 재시험을 모두 남긴다. 임의 PASS 파일이나 예시 수치를 결과로 쓰지 않는다. 키·연락처가 로그에 포함되지 않도록 확인한다.
- **결과:** 완성할 `docs/EXECUTION-RESULT.md`의 통과 수·시간·실패 사례를 각 보고서에서 재확인할 수 있어야 한다.
- **기준 문서:** [시나리오·평가 가이드](../../../docs/EVALUATION-GUIDE.md), [실행 결과서](../../../docs/EXECUTION-RESULT.md), [제출 안내](../../ohyun/SUBMISSION.md).
