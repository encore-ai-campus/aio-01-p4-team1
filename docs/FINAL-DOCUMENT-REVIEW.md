## 2. 선생님 체크리스트 46항목 대조

사용자가 전달한 「필수 3종 문서 마무리 체크리스트 · 수강생용」의 순서대로 **11+13+16+6항목**을 정리했다. 원본 파일명·SHA-256은 대조 기록에 남겼다. 아래 문장은 항목을 짧게 요약한 것이며, 공식 제출 원문 15개 체크리스트는 [결과서 6절](EXECUTION-RESULT.md#6-제출-전-체크리스트)에 유지했다.

- **문서 확인:** 현재 설명과 연결 근거를 대조했다. 전체 기능 통과를 뜻하지 않는다.
- **부분 확인:** 확인한 근거가 있으나 항목 전체를 입증하지 못했다. 제한을 함께 적었다.
- **미확인:** 실제 수행·승인의 근거가 없다.
- **승인 전:** 사용자가 별도로 승인할 작업이다.

## 3. 이번 문서 마감 뒤에도 남는 사항

1. **실패·한계 유지:** TM-04·TM-13, TM-12 정답 절 조건, Error 위치 unknown, N14 합성 결함과 app 강제 예외는 미수정이다.
2. **공식 전체 시험 미완료:** 원본 CLI는 인증 전달·route_in/서술 조건/하위 입력 판정 보완이 필요하고 독립 호환 러너는 미완료다. WF-10은 공용 Credential·외부 스크립트 의존, TM-14는 격리 주입 환경 부재로 실서비스 미실행이다. 키가 없어서 못 한 것이 아니다.
3. **운영 확인의 한계:** main 전체 배포·운영 RAG 원본별 DB 해시·새 DB 복원/자동 DLQ·전체 로그/과거 이력 비밀 검사는 확인하지 않았다. 운영 체크아웃 직접 pull은 data-api bind 경로에 영향을 줄 수 있다.
4. **사람이 확인할 마감:** 담당자 교차 검토, 역할별 리허설·발표자료 최종본, 사용자 최종 제출 승인과 제출 SHA·시각 기록이 남는다. 이번 문서 반영으로 대신 완료 처리하지 않는다.

시험 기대를 느슨하게 하거나 서비스를 고쳐 미완료를 숨기지 않는다. 이번 문서 마감의 목적은 발표와 제출 검토에서 **실행한 것·실패한 것·아직 확인하지 않은 것**을 같은 근거로 설명하는 데 있다.
