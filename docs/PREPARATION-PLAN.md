## 4. 선택·결정할 사항

- **최신 조합 제안:** A로 핵심을 검증하고 작은 C(웹 화면+FastAPI+DB)를 목표로 합니다. 외부 알림 1개는 후순위입니다. C 담당·환경 확보가 어렵다면 B 또는 A 범위를 승인 전에 조율합니다. 공통 시험 경로는 유지합니다.
- **역할:** 헌장의 담당 제안을 본인과 확인하고 확정합니다. 원민님 시험 결과서, 수언님 설명·시연 자료는 작업을 구분하고 함께 검토합니다.
- **RAG:** 같은 10문제로 청킹 2종 비교, 검색 점수·top_k는 측정 후 결정. 관리자 문서는 검색 전에 필터링합니다.
- **검증:** 공통 14유형 원본+팀 5개 이상, 기대값 먼저 작성. 구두 설명에서 허용된 시험 축소는 최종 적용 범위를 확인해 별도 기록합니다. 실패 원인·수정·재시험 증거를 남기고 미실행·제외를 통과로 계산하지 않습니다.
- **발표:** 담당자 모두 자기 흐름을 설명할 수 있게 준비합니다. 발표를 특정 한 사람에게만 맡기지 않습니다.
