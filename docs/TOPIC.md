# 주제 제안서 · 1팀

> 2026-11-02: 팀 주제는 사내 IT 헬프데스크로 결정. 강사 승인 대기. 회사 설정·범위·조합은 검토 초안입니다.

## 1. 주제 한 줄

가상 회사의 사내 직원을 위한 계정·VPN·메일·장비·소프트웨어 오류 및 보안 사고 접수 자동화. **회사 설정은 미정**이며, 기존 ‘온라인 유통회사 한빛커머스’는 설명용 제안입니다.

**11/02 회의 반영 제안: A 핵심 검증 → 작은 C 웹서비스 → 여유 시 외부 알림 1개.** 제공 직원·부서·문서·접수 번호를 활용합니다. 회의에서 합의한 것은 기본 주제와 서비스·연동에 집중하는 방향이며, C 선택 자체는 아직 미정입니다. 웹·API 연결 담당을 확보하지 못하면 B 또는 A의 완성 범위를 조율합니다. [구현 기획안](IMPLEMENTATION-PLAN.md)을 따르며 최종 시험 적용 범위는 강사 승인 때 확인합니다.

## 2. 큰 틀 조건

| 조건 | 충족 계획 |
| --- | --- |
| 기업 기술지원 | 직원의 업무 도구 오류를 사내 IT팀이 지원 |
| 지식 문서 | 제공 규정 8종·FAQ 6종으로 절차 안내 |
| 사람에게 이관 | 근거 부족·보완 질문 한도·보안·권한·긴급 문제는 IT팀 티켓 |
| 권한·개인정보 | 관리자 문서 검색 전 제한, 본인 접수만 조회, 연락처 마스킹 |
| 외부 장애 | data-api 티켓·조회·알림 및 LLM 장애에 대한 대체 경로 |

## 3. 문의 범위 제안

| 유형 | 처리 | 근거 |
| --- | --- | --- |
| 계정 | 일반 절차 안내, 잠금 해제·권한 조치는 이관 | password-policy |
| VPN | 환경·오류 확인 후 점검 안내 | remote-work-vpn |
| 메일·문서 | 용량·첨부·사용 절차 안내 | email-and-documents |
| 장비 | 기본 점검·지급·반납 안내, 고장 이관 | device-issue-return |
| 소프트웨어 | 허용 설치 절차 안내, 승인·관리자 작업 이관 | software-usage |
| 보안 사고 | 긴급 이관·알림과 안전한 초동 안내 | security-incident |

meeting-room·privacy도 색인과 개인정보 정책 확인에 활용합니다. 실제 계정 변경·PC 원격 제어·보안 조치 실행은 하지 않습니다. 별도 웹앱은 A 기본형의 필수 범위가 아닙니다.

## 4. 데이터

기본 데이터 API 그대로 사용: 규정 8종, FAQ 6종, 직원 6명, 기존 접수 4건. 관리자 전용 문서 1개도 단위 프로젝트 키트에서 확인합니다. 새 사용자·접수 데이터 5명/4건을 별도로 제작할 필요는 없습니다.

현재 제공 목록은 사용자 안내와 수업 문서 기준이며, 이 로컬의 Last3Mon/80 폴더는 아직 없습니다. 키트 확보 후 실제 파일·권한·API 인증을 확인합니다.

## 5. 공통 시나리오 예

| ID | 제공 사례 | 기대 |
| --- | --- | --- |
| WF-01 | 박서연의 VPN 연결 오류 | 자동 답변, remote-work-vpn 근거 |
| WF-05 | 이준호의 관리자 문서 요구 | 제한 문서 미검색·미노출, 권한 없음 또는 이관 |
| WF-12 | 박서연의 피싱 링크 클릭 + 본인 T-1002 상태 | high 티켓·알림·security-incident 초동 근거·본인 상태·마스킹 |

키트의 공통 14유형 원본을 보존하고 우리 시험 5개 이상을 별도로 추가합니다. 11/02 강사 구두 설명에는 일부 시험 제외를 허용하는 내용도 있어, 제외 시 대상·사유·평가 적용 범위를 확인해 기록합니다. 미실행·제외는 통과로 계산하지 않습니다.
