# 제출 캡처

- **작성:** 설계·실행 결과서와 발표에 실제 사용하는 n8n·웹 화면 캡처.
- **규칙:** 비밀번호·키·연락처를 가리고, 파일명에 시나리오와 장면을 드러낸다. 사용하지 않는 캡처는 넣지 않는다.
- **결과:** 관련 문서에서 각 캡처를 링크하고, 캡처가 실제 실행 보고서와 같은 결과를 보여야 한다.
