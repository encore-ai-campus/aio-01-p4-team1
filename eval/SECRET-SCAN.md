# 제출본 비밀 검사

공식 수업 도구 `tscan 0.1.0`을 설치한 환경에서 저장소 루트에서 실행한다.

```sh
tscan scan . --json
tscan staged --json
```

전체 작업 트리를 읽되 제출 대상이 아닌 빌드 산출물·로컬 비공개 설정은 판정에서 제외한다. 이 경로가 Git에 추적되지 않는지도 별도로 확인했다. Git 과거 이력·바이너리 이미지 내용은 텍스트 검사 범위가 아니며, 새 캡처는 화면을 직접 검토했다.

## 오탐·가상 데이터 예외

[.tscanignore](../.tscanignore)는 검토한 오탐·고정 가상 데이터의 예외 목록이다.

- 잠금 파일에서 숫자 버전을 이메일로 인식한 348건을 확인하고 이메일 종류만 예외 처리했다. 다른 키 검사는 유지한다.
- 나머지는 위치가 고정된 28개 행이다. 패키지 명령 10개·참고 localhost URI 1개, 가림 시험 입력/기대값 10개, 제공 가상 티켓 데이터 4개, 로컬 가상 계정 2개, 공식 도구의 의도된 무효 시험 키 1개다.
- 가상 연락처를 지우면 마스킹 시험과 제공 원본이 달라지므로 데이터를 보존했다. 문서·실행 보고서에는 실제 연락처·키를 남기지 않는다.
- 공식 `tools/flow.py`는 바꾸지 않았고 원본 SHA-256 일치를 확인했다.
- 예외 대상 행이 바뀌면 예외를 그대로 신뢰하지 말고 재검토한다. [검사 기록](../runs/secret-scan-20261108.json)에 각 행의 해시와 이유를 남겼다.

## 실제 수행 결과

전체 검사 0건·종료 코드 0을 확인했다. 별도로 인계받은 실제 비밀번호·키와 로컬 비공개 설정값이 Git 추적 텍스트에 그대로 들어 있는지 메모리에서 비교했으며 일치 0건이다. 값 자체는 출력·보고서·Git에 넣지 않았다.

n8n owner 로그인 이메일은 계정 식별 정보이므로 VM 안내 문서에서 비공개 인계로 바꿨다. 서비스 계정·비밀번호나 n8n 설정은 변경하지 않았다.

이 결과는 명시한 규칙·범위의 검사 결과이며 모든 형태의 미지 비밀값이 존재하지 않음을 수학적으로 증명하는 것은 아니다.
