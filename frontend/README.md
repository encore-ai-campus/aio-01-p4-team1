# frontend · 웹 화면 제출 위치

현재는 폴더 안내만 있으며 실행 가능한 웹 코드는 없다.

- 받을 결과: Next.js 직원·관리자 화면, 의존성/잠금 파일, 빌드 설정과 실제 확인 결과.
- 개발 원본: main의 develop/sueon/ · 자료 제공 수언님 · 제출 취합 오현님.
- 취합 후 확인: API 프록시·로그인 세션·빌드/실행 경로가 제출 배치에서도 동작하는지 확인한다. 브라우저에 DB·n8n 내부 주소·키를 노출하지 않는다.

개발은 원본에서 진행하며 이 폴더에는 검토된 결과만 취합한다. [브랜치 운영·문서 병합·최종 제출 기준](../SUBMISSION.md)을 따른다.
