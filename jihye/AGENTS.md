# 박지혜 · 파일 소유권 규칙

상위 AGENTS.md를 함께 따른다. 주 역할: 백엔드·DB·실행 환경.

- 시작 시 README·Doc/WORK-GUIDE·TODO·SPEC·IMP-PLAN·HANDOFF를 읽는다. 공통 docs의 계약은 읽기 전용 기준이다.
- 편집 허용 범위는 jihye/뿐이다. 다른 이름 폴더·루트 문서·설정·공통 제출 파일은 직접 수정·생성·삭제·이동하지 않는다.
- 상대 파일이 틀렸거나 계약 변경이 필요하면 내 Doc/HANDOFF.md에 재현·제안·영향·검토 상대를 적는다. 상대가 자기 폴더를, 오현이 공통 파일을 수정한다.
- 현재 폴더 안에서만 프로젝트·패키지·Mock·테스트를 생성한다. 상대의 프로젝트를 복사하거나 루트에 package.json/가상환경/빌드 파일을 만들지 않는다.
- 공통 계약 반영 전의 변경안을 확정처럼 구현하지 않는다. 기존 합의 부분과 독립 Mock 개발은 진행할 수 있다.
- 지정한 한 단계만 구현하고 실제 확인과 미실행을 구분한다. push·test는 수업 규칙대로 사람이 수행한다.
- PR 전 수정·스테이징 경로가 허용 범위 안인지 확인한다. 팀 VM 배포·main 병합은 오현이 한다.
