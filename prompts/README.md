# prompts · 프롬프트 제출본

기준 커밋 `ca94191`의 `data-api/data/prompts/`에서 `helpdesk-p1.md`, `helpdesk-p2.md`, `helpdesk-p3.md`를 원문 그대로 복사했다. 제공 프롬프트 자산의 제출용 사본이며, 실제 워크플로우에 적용된 설정은 [워크플로우](../workflows/)와 [설계서](../docs/WORKFLOW-DESIGN.md)를 따른다.

개발 원본과 VM의 `data-api/` 경로는 유지한다. 기능 수정은 개발 원본에서 진행한 뒤 제출본에 반영한다.
