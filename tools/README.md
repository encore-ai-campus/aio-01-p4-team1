# tools · 공식 수업 시험 도구 원본

[flow.py](flow.py)는 선생님 수업 저장소의 79일차 도구를 수정 없이 포함한 파일이다. 출처·원본 커밋·SHA-256은 [COURSE-SOURCE.json](COURSE-SOURCE.json)에 기록한다.

이 main 안에 원본을 포함했으므로 파일을 가져오기 위해 다른 브랜치나 로컬 수업 저장소를 참조할 필요가 없다. 원본은 Python 3.10 이상과 표준 라이브러리를 사용하며, 게시 등 일부 명령에는 실행 환경의 Docker·n8n이 필요하다.

현재 단계는 **원본 준비 완료**다. 웹훅 인증 처리, 현재 워크플로우·시나리오와의 호환성 확인, 실제 check·push·test는 이번 단계에서 진행하지 않았다. 실행 방법이 검증되기 전에는 이 파일의 존재를 공식 전체 재현 완료로 해석하지 않는다.

원본 `push`는 n8n 가져오기·게시·재시작을 수행하고, `fault`·`llm`·초기화 명령은 대상 서비스 상태를 변경한다. 이 단계에서는 도구를 실행하지 않고 원본 해시와 Python 구문만 확인했다. 후속 작업은 사용자가 지정한 범위와 대상에서 진행한다.
