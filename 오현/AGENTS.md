# 오현 작업 범위

상위 AGENTS.md와 공통 docs의 계약을 함께 따른다.

- 주 담당 역할: 팀장·통합.
- 오현/Doc/와 루트 공통 문서를 관리하고, PR 승인·병합·팀 VM 배포·제출 취합을 맡는다.
- 코딩 에이전트의 현재 작업 디렉터리는 이 이름 폴더다. 공통 계약은 저장소 루트의 docs/API-CONTRACT.md를 읽는다.
- Doc/SPEC.md와 Doc/IMP-PLAN.md의 지정 단계만 작업한다. 실제 확인 없이 완료 표시를 하지 않는다.
- 다른 이름 폴더와 공통 문서의 변경이 필요하면 이유·영향을 알리고 연결 담당자와 조율한다.
- 명령·파일 경로는 현재 이름 폴더 기준인지 저장소 루트 기준인지 표시한다.
