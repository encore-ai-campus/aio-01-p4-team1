## 💡 각 문서 포함 내용
각 문서에는 다음 내용이 공통적으로 정리되어 있습니다:
1. **1분 요약** (해결할 문제, 만들 서비스, 들어올 문의 예시)
2. **만드는 범위와 멈춰야 하는 지점** (자동 처리 vs 상담사/IT팀 이관)
3. **업무 흐름도 (Mermaid 다이어그램)**
4. **필요한 가상 데이터 세트** (FAQ, 정책, 문제 해결 가이드, 티켓 등)
5. **시험할 질문 목록** (정상 처리 케이스, 이관 케이스, 예외 케이스)
6. **강사님 기본 주제와의 연계 및 차별점**
